# Mt Zion House of Prayer — website

The church website. Plain HTML pages, hosted free on Netlify. Every change pushed
to GitHub goes live automatically within a minute or so.

**To make a change**, open this folder in Claude Code and ask in plain words, e.g.
"add this week's bulletin" (and attach the PDF), or "change worship to 10:45".
Claude knows how the site is organized (see `CLAUDE.md`).
